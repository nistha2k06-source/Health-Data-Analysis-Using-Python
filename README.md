 Health Data Analysis Using Python

📌 Project Overview
Health Data Analysis Using Python is a Python Programming mini-project that demonstrates how health-related data can be processed, analysed, and visualised using Python libraries.

The project uses a sample dataset of 10 patient records containing age, gender, blood pressure, cholesterol, and heart rate.

🎯 Objectives
- To organise and analyse sample health data.
- To check missing values and validate numerical data.
- To calculate average health measurements.
- To filter records based on blood pressure.
- To visualise patient data using graphs.

🛠️ Technologies Used
- **Python** — Main programming language
- **Pandas** — Data loading, cleaning, and manipulation
- **NumPy** — Numerical operations and data validation
- **Matplotlib** — Data visualisation
- **CSV** — Storing structured health data

📊 Project Features
- Displays sample patient records.
- Checks missing values in the dataset.
- Validates age, blood pressure, and cholesterol values.
- Calculates average age, blood pressure, cholesterol, and heart rate.
- Filters records with blood pressure above 140.
- Displays gender-wise patient counts.
- Creates an age distribution histogram, a gender-wise bar chart, and scatter plots for age versus blood pressure and cholesterol.
- Saves processed data and graphs to files.

▶️ How to Run
1. Install Python.
2. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib
   ```

3. Run the Python source code in VS Code or Python IDLE.
4. View the generated CSV files and graphs.

⚠️ Limitations
- The project uses a small synthetic dataset of 10 sample records.
- The results depend on the quality and size of the dataset.
- The project is educational and does not provide medical diagnoses or treatment recommendations.

📝 Conclusion
This project demonstrates the basic process of validating, analysing, and visualising sample health data using Python. It provides practical learning in data cleaning, statistical calculations, filtering, and graphical representation.
